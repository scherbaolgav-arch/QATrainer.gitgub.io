# QA Trainer

Учебный проект для начинающих тестировщиков.

## Возможности

- Поиск дефектов в форме Email
- Проверка найденных багов
- Написание Bug Report
- Практика составления чек-листов
- Практика написания тест-кейсов
- Поиск ошибок в JavaScript

## Используемые технологии

- HTML
- CSS
- JavaScript

## Реализовано

✔ Бургер-меню

✔ Валидация Email

✔ Подсветка правильных и неправильных ответов

✔ Тренажёр Bug Report

✔ Toast-уведомления

## В планах

- Сохранение результатов
- Фильтрация заданий
- Категории багов
- Статистика пользователя
